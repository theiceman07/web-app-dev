Error codes

Each tile opens that page and answers with its real HTTP status code, so you can also see it in your browser's network panel. 202 is not an error: it means the request was accepted. FC-100 is specific to FoleyCraft.

Try them live

Add ?simulate=CODE to any address and the site answers with that code for real: an error page for pages, a JSON error for /api/ addresses. Some codes also happen on their own:

  • /?simulate=502 and /api/faqs/?simulate=504: any code, on any page or API.
  • FC-000 offline: open the site once, turn off Wi-Fi, then reload. The service worker shows the offline page (or try /?simulate=offline).
  • 404: /no-such-page/. 410: /beta/, a page removed for good.
  • 405: /api/assistant/ only accepts POST. 413: any request body over 1 MB.
  • 401 / 403 / 404: ticket lookups at /api/tickets/<ref>/. 429: more than 20 assistant messages a minute.
  • 503: health when the database is down. FC-100: the assistant when the AI is slow or down.
